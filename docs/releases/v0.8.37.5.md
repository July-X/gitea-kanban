# v0.8.37.5 · GitGraph ref badge tag icon 替换为 Octicons tag SVG

## 问题

v0.8.37.4（commit `e20ac7f`）只把 branch icon 替换成 Octicons `git-branch-fill`，tag icon
保留 lucide `Tag`（stroke 线条形态），导致 ref badge 视觉不一致：branch 是实色 fill + 白色
icon，tag 是线条描边 + 白色 icon（fill=none 默认透明）。

用户 mid-turn 提供精确 Octicons tag SVG path（11 节点，斜挂标签 + 圆孔 + 折叠尾巴），
对齐 v0.8.37.4 branch icon 模式，统一两个 ref badge icon 的视觉语言。

## 改动

### 1. 模板：lucide Tag → inline Octicons tag SVG

`frontend/src/views/TimelineNewView.vue:2800-2811`：

替换前（v0.8.37.4）：
```html
<Tag v-if="r.commit.refTypes?.[idx] === 'tag'"
     :size="9"
     class="ref-badge__icon ref-badge__icon--tag"
     aria-hidden="true" />
```

替换后（v0.8.37.5）：
```html
<svg v-if="r.commit.refTypes?.[idx] === 'tag'"
     class="ref-badge__icon ref-badge__icon--tag"
     xmlns="http://www.w3.org/2000/svg"
     width="15" height="16" viewBox="0 0 15 16" aria-hidden="true">
  <path fill="currentColor" fill-rule="evenodd"
        d="M7.73 1.73C7.26 1.26 6.62 1 5.96 1H3.5C2.13 1 1 2.13 1 3.5v2.47c0 .66.27 1.3.73 1.77l6.06 6.06c.39.39 1.02.39 1.41 0l4.59-4.59a.996.996 0 0 0 0-1.41L7.73 1.73zM2.38 7.09c-.31-.3-.47-.7-.47-1.13V3.5c0-.88.72-1.59 1.59-1.59h2.47c.42 0 .83.16 1.13.47l6.14 6.13-4.73 4.73-6.13-6.15zM3.01 3h2v2H3V3h.01z" />
</svg>
```

- viewBox 15×16（vs branch 10×16，宽度按比例更宽）
- 高度 16px 撑满 18px icon 容器，宽度 15px（viewBox 原始比例），flex 居中在 18×18 icon 容器内
- `fill="currentColor"` → 被父 `.ref-badge__icon--tag` CSS `fill: #ffffff` 覆盖为白色

`frontend/src/views/TimelineNewView.vue:19`：

`frontend/src/views/TimelineNewView.vue:3919-3924`：
