## 最终设计

### 状态 1：默认态（图 008）

- **背景**：lane 色 20% alpha tint（`withAlpha(colorHex, 0.2)`，参考 vscode-gitlens [`colors.ts:137`](https://github.com/gitkraken/vscode-gitlens)）
- **文字**：`#E6EDF3` 浅字（dark theme 风格）
- **icon 块**：lane 色实色 + 1px lane 色 darker 边框 + 白色 fill icon（Octicons `git-branch-fill`）

### 状态 2：hover / dot-active（图 010）

- **背景**：白色 pill 实色（`var(--color-bg-elevated)`）
- **文字**：`#0f1115` 深字（反相）
- **icon 块**：**保持 lane 色实色 + 白色 icon**（视觉锚点不变）
- 加 `box-shadow: 0 0.1rem 0.6rem rgba(0, 0, 0, 0.25)` 浮起效果

### 几何验证

- `.ref-badge` height 20px + line-height 18px + box-sizing border-box
- `.ref-badge__icon` width/height 18px（border-box → 16px 内容）+ 1px border + 5px margin-right
- SVG 10×16 在 16×16 内容区垂直填满，水平居中（左右各 3px 留白）
- icon 块 border-radius 6px 跟父 badge 5px 衔接（左对齐无接缝白线）
- icon 块始终 lane 色填充（视觉锚点），badge 主体根据 hover 状态切换
