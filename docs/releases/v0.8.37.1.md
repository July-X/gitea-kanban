# v0.8.37.1 — ref badge 回退到「默认透明 + hover 填充」模式（对齐 vscode-gitlens）

## 背景

v0.8.35.3 (commit 763e0ad) 把 ref badge 改成「默认就是 hover 后的样子」——`.ref-badge` 默认 `background-color: var(--row-lane-color)` 实心填充 + `color: var(--color-shell-main-bg)` 深色文字（lane 色背景 + 黑字），删除 `.ref-badge:hover` 和 `.commit-row--dot-active .ref-badge` 两条 hover 变体。动机是用户上一轮反馈「badge 颜色默认就是 hover 后的样子」，但**视觉上跟 vscode-gitlens `.gl-graph__ref-pill` 风格相反**（gitlens 默认是透明 bg + lane 色 border + 浅字 + hover 填充）。

本 commit 把 ref badge 回退到 v0.8.35.3 之前（即 v0.8.35.2）的视觉状态，**保留后续 v0.8.35.4 的尺寸微调**（badge 22px + icon 20px + SVG 9 + margin-right 5）。回退后：

- `.ref-badge` 默认 `background-color: transparent` + `color: #E6EDF3` 浅字 + `border: 1px solid var(--row-lane-color)` lane 色边框
- `.ref-badge:hover` 恢复：背景填充 lane 色 + 文字变深

跟用户 2026-08-01 06:43 截图 `.reasonix/attachments/clipboard-20260801-064344.133003-000002.png`（v0.5.1 徽章为深灰底 + 白色文字 + 绿/橙色 icon 块）完全对齐——这就是 vscode-gitlens 的 `.gl-graph__ref-pill` 风格。

### 2. 恢复 `.ref-badge:hover` 填充变体

/* v0.8.37.1：恢复 hover 填充变体（对齐 vscode-gitlens .gl-graph__ref-pill:hover）

### 3. 底边线被裁掉修复（mid-turn steer 反馈）

mid-turn 用户反馈：「badge 的底边线显示不全，看起来想丢失了一样」。

**根因**（v0.8.37 埋的雷）：`VSCODE_GRID_Y = 28 → 24`（v0.8.37 改的）让 commit-row 高度从 28px 缩到 24px，但 `.ref-badge` 仍然 `height: 22px` + `border: 1px solid` + 继承全局 `box-sizing: border-box`（`frontend/src/styles/reset.css:11` `* { box-sizing: border-box }`）：

- border-box 下 `height: 22px` = 1px border-top + 20px content + 1px border-bottom = 22px 总高
- 24px row + flex `align-items: center` 居中：badge 顶 2px, 底 22px → 距 row 底 24px 还有 2px 缓冲
- 但 `.commit-row__col` 第 3902 行 `overflow: hidden` + WebView sub-pixel 抗锯齿下底边 1px border 经常被描述成「丢失了一样」

**修法**（同时缩 2px，建立 2px 缓冲）：

**`frontend/src/views/TimelineNewView.vue:3828-3836` `.ref-badge`**：

```css
/* v0.8.37.1（mid-turn steer）：badge 高度 22 → 20px（border-box：1px border-top + 18px content + 1px border-bottom = 20px 总高） */
line-height: 18px;
height: 20px;
padding: 0 8px 0 0;
box-sizing: border-box;  /* 之前继承全局 border-box，本版显式声明 + 注释 */
```

**`frontend/src/views/TimelineNewView.vue:3843-3868` `.ref-badge__icon`**：

```css
/* v0.8.37.1（mid-turn steer）：icon 容器 20 → 18px（badge 内容区 18px 100% 匹配） */
width: 18px;
height: 18px;
box-sizing: border-box;  /* 之前 content-box + 20px 装在 18px 内 box 偏差 2px，本版彻底统一 border-box */
```

**几何验证**（24px row center 居中）：

- badge 20px 顶 2px / 底 22px → 距 row 底 2px 缓冲 ✅
- icon 18px 装在 badge 18px 内容区 100% 匹配，无像素裁剪 ✅
- Tag/GitBranch SVG 9px 装在 18px 容器内部居中，4.5px 上下留白 ✅
- 大小写保持 v0.8.35.4 缩 10% 风格（badge 20px ≈ icon 18px + 1px border 衔接）
