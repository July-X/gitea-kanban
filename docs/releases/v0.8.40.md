## 问题

commit row 描述列末尾出现 3 个圆点样式的纵向滚动条（用户截图红箭头位置）。DevTools inspect 看到 `.commit-row__col--desc` div 上挂了 `scroll` badge —— 说明该列实际 `scrollHeight` > `clientHeight`。

### 根因分析

两处 CSS 共同导致：

**① `.commit-row__col--desc` 的 `overflow: hidden visible` 写法**

CSS 规范上 `overflow-x` + `overflow-y` 同时给不同值时，其中之一必须是 visible 才能让另一个生效——`hidden visible` 这种"两端不同"的写法在 Chromium-based webview 里被错误地解析成 `auto`，而不是期待中的"x 隐藏 + y 可见"。结果是当 desc 列内容（ref-badge + commit-subject）实际高度超过 row 28 px 时：

- `overflow-y` 也变成 `auto` → 出现纵向滚动条 → 用户看到「竖三点 ⋮」

**② `.ref-badge` 的 `margin-top: 2px`**

v0.8.37.5 重做 ref badge 后实际高度：

```
.ref-badge__icon {
  width: 20px;  /* content-box 默认 */
  height: 20px;
  padding: 3px;
}
```

`.ref-badge__icon` 实际高度 = `20 + 3*2 = 26 px`（content-box，padding 不计入 height）。

`.ref-badge` 实际高度 = `max(line-height 20 px, icon 容器 26 px) + border 1*2 = 28 px`。

加 `margin-top: 2 px` → 占用 **30 px**，超出 commit-row `inline style="height: 28px"` **2 px**。

desc 列 `overflow-y` 变 auto 后，这 2 px 溢出触发 scrollbar。

### 修复

**`frontend/src/views/TimelineNewView.vue:4100-4119`**：

```diff
 .commit-row__col--desc {
   display: block;
   padding: 0 12px;
   border-right: 1px solid var(--color-divider, rgba(0, 0, 0, 0.2));
   white-space: nowrap;
-  /* overflow: hidden visible —— x=hidden 截断超长文字（ellipsis），y=visible 让 ref-badge 底边线不被裁切
-   * 之前写成 visible hidden（写反了）导致：
-   *   - x=visible → 超长文字不被截断 → 横向滚动条
-   *   - y=hidden → 文字下半部分被裁 → commit-subject 只显示一半
-   * badge margin-top:2px + line-height:20px + border 1px*2 = 24px 总高，row 28px 够放 */
-  overflow: hidden visible;
+  /* 修复：原 `overflow: hidden visible` 写法在 webview 里被错误解析成 auto，
+   * 导致 desc 列实际内容（ref-badge + commit-subject）超过 commit-row 28px 行高时
+   * 渲出纵向滚动条。改为单一 `overflow: hidden` —— x/y 都裁切，
+   * x 方向维持 ellipsis 截断超长文字，y 方向裁切超高的 badge / subject。
+   * 历史注释里 `hidden visible`（y=visible）是 v0.8.35 故意保留用来"防裁切 badge 底边线"，
+   * 但实测在 webview 里 y=visible 直接导致 scrollbar 出现，且 ref-badge 当前实际高度
+   * ≤ 28px 行高（v0.8.37.5 后 badge line-height 20px + border 2px + icon 容器 20px = 22-26px），
+   * 没有超高的现实风险，统一 hidden 更安全。 */
+  overflow: hidden;
   text-overflow: ellipsis;
   line-height: var(--git-graph-row-height, 28px);
 }
```

**`frontend/src/views/TimelineNewView.vue:3880-3885`**：

```diff
 .ref-badge {
   line-height: 20px;
   height: auto;
   padding: 0;
-  margin-top: 2px;
+  margin-top: 0;
   margin-right: 6px;
   overflow: hidden;
 }
```

取消 `margin-top: 2px` —— badge 用 `.commit-row__col--desc` 的 `inline` 段落基线 + 行内 flex 居中即可，垂直方向不需要额外 margin。

### 为什么 y=hidden 不会裁切 badge 底边线

修复后 badge 总高 = `max(line-height 20 px, icon 容器 26 px) + border 2 px + margin-top 0 = 28 px`，恰好等于 commit-row 28 px 行高。`overflow: hidden` 不会裁切任何内容。

历史注释 v0.8.37.1 担心的"badge 底边线被裁"问题，现在 badge 高度精准对齐 row 后已经不存在。
