## 问题背景

v0.8.25 起 Graph 算法默认切换到 GitLens GKC（`BuildGraphGitlens`，`5caa347`），但保留了两条历史 fallback 链路：

| 资产 | 当前状态 | 处置 |
|---|---|---|
| `app/git/graph/layout.go`（749 行） | `BuildGraph` 仅在注释中被引用，正文无任何调用 — **孤儿代码** | 删除 |
| `app/git/graph/layout_vscode.go`（650 行） | 通过 env 开关 `GITEA_KANBAN_GRAPH_ALGO=vscode` 接 `pickGraphBuilder` fallback | 删除 |
| `app/platform/gitea/adapter.go:pickGraphBuilder` | 默认走 GitLens；env=vscode 退回 vscode-git-graph | 收敛为单调用 |
| `app/platform/github/adapter.go:pickGitHubGraphBuilder` | 同上 | 收敛为单调用 |
| `layout_vscode.go` 配套测试（4 个文件） | `v0824_main_chain_test.go` / `layout_uncommitted_test.go` / `layout_test.go` / `v27_regression_test.go` | 全删 |
| `layout_gitlens_e2e_test.go:220` vscode baseline 对照块 | 与 fallback 配套的对照测试 | 删除 |

保留 vscode fallback 的理由是「万一 GitLens 移植有 bug 用户可一键回退」。经过 v0.8.25 的 5 个 bug 修（`1bc9fbc`/`e9ed576`/`1acdfcb`/`b86a0fd`/`b989f9f`）+ v0.8.25.x 后段的 fork/merge/形态 4 修（`64499be`），Graph 已经稳定 2 周没回归。fallback 链路本身成了维护负担 — 用户拍板全删，干净一刀。

## 改动内容

### 1. 两个 adapter 的 pickGraphBuilder 收敛为单调用

**`app/platform/gitea/adapter.go`** 与 **`app/platform/github/adapter.go`**：

- 删 `pickGraphBuilder` / `pickGitHubGraphBuilder` 函数体（内含 `os.Getenv("GITEA_KANBAN_GRAPH_ALGO") == "vscode"` 分支）
- 删 `os` import（仅 adapter 用的 env 读取）
- 改为直接调 `graph.BuildGraphGitlens(logResult.Commits, head, pinned)`

### 2. layout_vscode.go + 4 个测试文件删除

```text
app/git/graph/layout_vscode.go              (650 行, 删)
app/git/graph/v0824_main_chain_test.go      (v0.8.24 幽灵 line 修复测试, 删)
app/git/graph/layout_uncommitted_test.go    (Uncommitted 行渲染测试, 删)
app/git/graph/layout_test.go                (BuildGraph 测试, 删)
app/git/graph/v27_regression_test.go        (v2.7 first-parent 修复回归, 删)
```

`v0824_main_chain_test.go` 是历史上 v0.8.24 修幽灵 line 时的回归测试。v0.8.26 中幽灵 line 修复已被 GitLens 算法 1:1 继承（`determinePath` 的 main chain 锚定策略对应到 `assignColumnForRow` 的 main chain reservation），删除不会降低覆盖。

### 3. layout_gitlens_e2e_test.go vscode baseline 对照块删除

文件保留（仍是 GitLens 真实数据 e2e 测试），line 220 附近 vscode `vcResult := BuildGraphVscodeWithHead(...)` + 对照断言删除。

### 4. layout.go 删除 + 共享类型迁到 types.go

**`app/git/graph/layout.go`**（749 行孤儿代码）删除；之前共享给 vscode/gitlens 双实现的 DTO 类型（`GraphNode` / `GraphEdge` / `GraphBranchLine` / `GraphBranch` / `EdgeType` 常量块 / `GraphResult`）整体迁移到 **`app/git/graph/types.go`**（237 行），并补 `HasPrimaryBranchRef` 函数的 import 路径（之前散在 layout.go）。`BuildGraphGitlens` 直接复用 types.go 里的 DTO，前端 `vscode-render.ts` 不需改（DTO schema 字段全等）。

### 5. 注释清理

`layout_gitlens.go` 文件头注释去掉「保留为 fallback」表述，改为：

```go
// v0.8.26：layout_vscode.go / layout.go / pickGraphBuilder env 开关全删，
// 本文件为 graph 包唯一入口。
```

`app/platform/gitea/adapter.go` 内 `BuildGraphGitlens` 调用处加 v0.8.26 块注释（说明不再有 fallback），同时删 v0.8.25 env 切换描述。
