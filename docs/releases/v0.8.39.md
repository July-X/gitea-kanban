## 1. macOS .app 签名验证（P1 安全修复）

### 问题

`applyMacOS` 从 dmg 提取 .app 后直接启动 helper 脚本替换，**没有任何身份/签名验证**。恶意 dmg 或被劫持的 release 可直接替换 .app 安装任意代码。

### 参考实现

DeepSeek-Reasonix `desktop/updater_mac.go:verifyMacApp`：三层验证链。

### 修复

新增 `verifyMacApp(appPath, logger)` 函数，在 ditto 提取 .app 到 staging 后、启动 helper 脚本前执行：

1. **CFBundleIdentifier 匹配**（必须通过）— `PlistBuddy` 读取，验证 = `com.wails.gitea-kanban`
2. **codesign 验证**（必须通过）— `codesign --verify --deep --strict`，ad-hoc 签名也能过
3. **spctl 公证检查**（best-effort）— 当前 build 未 Developer ID 签名+公证，spctl 会失败但不阻断，只记日志警告；将来签名后改为强制

验证失败 → 清理 staging + 返回 `ErrApplyFailed`，不启动 helper 脚本。

### 新增常量

```go
const macBundleID = "com.wails.gitea-kanban"
```

来源：`build/darwin/Info.plist` 模板 `com.wails.{{.Name}}` + `wails.json` `name=gitea-kanban`。

## 2. Windows graceful shutdown（P1 数据安全修复）

### 问题

`applyWindows` 在 NSIS installer 拉起成功后直接调 `os.Exit(0)`，**跳过 Wails `OnShutdown` 回调**，可能丢失未保存数据（DB 未 flush、子进程未清理等）。

### 参考实现

DeepSeek-Reasonix `updater_app.go:installPortableUpdate`：先调 `a.shutdown(a.ctx)` 持久化状态 → 停止子进程 → 再 `os.Exit(0)`。

### 修复

**`app/updater/updater_windows.go`**：
- `applyWindows` 不再调 `os.Exit(0)`，改为返回 `ErrInstallerLaunched` 哨兵错误
- UAC 取消 / 其他失败路径不变

**`app/updater/verify.go`**：
- `ErrInstallerLaunched` 定义在跨平台的 `verify.go`（不是 `//go:build windows`），确保 macOS 构建也能编译

**`app_updater_app.go`**：
- `InstallUpdate()` 用 `errors.Is(err, updater.ErrInstallerLaunched)` 识别此信号
- 收到后走统一 `wruntime.Quit` → `OnShutdown` 回调 → 进程退出流程
- macOS 走相同路径（helper 脚本已 detached，主进程退出触发替换）

### 流程对比

| 步骤 | 旧（v0.8.38） | 新（v0.8.39） |
|---|---|---|
| 1 | `ShellExecuteExW` 拉起 NSIS | `ShellExecuteExW` 拉起 NSIS |
| 2 | `os.Exit(0)` **直接退出** | 返回 `ErrInstallerLaunched` |
| 3 | ~~OnShutdown 回调被跳过~~ | `InstallUpdate` 收到信号 |
| 4 | — | 延迟 300ms（让前端拿完 RPC 响应） |
| 5 | — | `wruntime.Quit` 触发 `OnShutdown` |
| 6 | — | OnShutdown 回调：持久化数据 / 关闭 DB / 停止子进程 |
| 7 | — | 进程退出 → NSIS 接管覆盖文件 |

## 3. 更新提示整合到 StatusBar

### 问题

原 `UpdateBanner.vue` 是 AppShell 顶部 40px 蓝色横条，硬编码 `#1a73e8`，不适配 dark/light 主题。

### 修复

更新提示从顶部 Banner 整合到 `StatusBar.vue` 右侧紧凑指示器：

**状态机 UI**：

| 状态 | 显示 | 按钮 |
|---|---|---|
| `available` | `[Download icon] 新版本 vX.Y.Z` | `[下载]` `[×]` |
| `downloading` | `[Loader2 spin] 下载中 45%` + mini 进度条 | — |
| `verifying` | `[Loader2 spin] 校验中…` | — |
| `downloaded` | `[RotateCw icon] 已就绪` | `[重启以安装]` `[×]` |

macOS 未签名 build：`[下载]` 按钮变为 `[下载页]`（打开浏览器）

**主题适配**：全部使用项目 CSS 变量，dark / light 自动切换：

| 元素 | CSS 变量 |
|---|---|
| 指示器背景 | `--color-primary-soft` |
| 指示器边框 | `color-mix(in srgb, var(--color-primary) 30%, transparent)` |
| 文案颜色 | `--color-primary` |
| primary 按钮 | `background: var(--color-primary)` + `color: var(--color-text-inverse)` |
| 进度条 | `background: var(--color-primary)` |

**文件变更**：
- `StatusBar.vue` — 新增 `useUpdate` composable + 更新指示器 UI + CSS
- `AppShell.vue` — 移除 `<UpdateBanner />` 引用
- `UpdateBanner.vue` — 标记 `【v0.8.40 已废弃】`，文件保留供 git blame
