# v0.8.35.1 — ref badge 回退 + 改回紧凑 row 24px

## 问题

v0.8.35（commit `14b0cefb`）把 row 高度从 24 → 50px + badge 从 18 → 37px，
试图对齐 vscode-gitlens ref-pill 设计 + 用户参考图。但用户截图反馈
「这个 UI 改的太丑陋了，好好改啊」——badge 撑爆 row，row 间隔拉到 75px，
视觉重心严重失衡：

- 文字只占 17-19px
- badge 撑到 75px（跟整 row 一样高）
- 整个 graph 看起来「稀稀拉拉 + badge 像巨型把手」

## 根因

```
每行 row 实际高度 = 50px（VSCODE_GRID_Y）+ 上下 padding
                 ≈ 75px（用户截图实测）
```

badge 37px 高 + 上下 padding 13px 各 = 63px（已经超过 50px row），
badge 撑爆 row，layout 强行扩展到 75px。文字 13px vs badge 37px 视觉
权重失衡——用户说"丑"是这种感觉。

## 修复

回退到 v0.7.x 紧凑设计：

| 元素 | v0.8.35 (回退) | v0.8.35.1 (这次) | 备注 |
|------|----------------|------------------|------|
| `VSCODE_GRID_Y` | 50 | **24** | 跟 v0.7.x 一致 |
| `.ref-badge` height | 37px | **18px** | 跟 row 高度 24 对齐（行内 75%）|
| `.ref-badge` padding | 0 12px | **0 6px** | 紧凑 |
| `.ref-badge__icon` | 30x30 | **16x16** | 跟 badge 高度匹配 |
| `.ref-badge__icon` margin-right | 0 | **4** | 跟 label 间距 |
| Tag/GitBranch SVG size | 24 | **12** | 跟 16px icon 匹配 |

**保留 v0.8.35 的视觉升级**：
- `color: #E6EDF3` 白色文字（不写死 `var(--color-text)`）
- `background-color: transparent`（rest 状态透明，hover 填充 lane 色）
- `border-color: var(--row-lane-color)` 跟 commit 所在 lane 同色
- `stroke: currentColor`（hover 时 SVG 跟随 badge 文字色变）

## 验证

- pnpm typecheck OK
- 视觉：badge 16x16 icon + 18px 高度 + row 24px = badge 跟 row 文字基线对齐，不撑爆

启动应用，切换到 `July-X/gitea-kanban` 仓库：

3. badge 视觉重心跟文字匹配，不再喧宾夺主
