# v0.8.37 — GitGraph 前端 UI 复刻 vscode-office 视觉（手风琴保留）

## 背景

v0.8.36 把算法对标切到 vscode-office（commit 98df580），但前端 UI 仍走 vscode-git-graph 风格（shadow 双层 + 28px 行高 + 16px offsetX + HEAD/stash 单圈），用户看到的视觉还是老的。本 commit 是 v0.8.36 之后的"前端 UI 跟进"——把对齐目标从 css 算法层延伸到渲染层，同时**保留手风琴交互**（用户拍板）。

之前 v0.8.37 的预期工作量（gitgraph-engine.md §10.8 列出）：shadow 去掉 + ref badge CSS var 染色 + dot 半径 4/HEAD 6 + 保留手风琴。**本次实际完成**：shadow 去掉 + GRID_Y 28→24 + offsetX 16→8 + HEAD dot 4→6 + stash 双圈 + 测试断言更新。**ref badge CSS var 染色已在 v0.7.4 ~ v0.8.35 期间逐步完成**（`.ref-badge` 当前走 `var(--row-lane-color)`），无需额外改动。

## 改动

### 1. 去掉 path shadow 双层渲染（vscode-office 单层）

**`frontend/src/lib/gitgraph/vscode-render.ts:246-270` `addPath()`**：

```ts
// v0.8.37
const addPath = (color: number, dStr: string, order: number, isCommitted: boolean): void => {
  const baseHex = VSCODE_COLORS[color % VSCODE_COLORS.length] ?? VSCODE_COLORS[0]!;
  const finalHex = isCommitted ? baseHex : VSCODE_UNCOMMITTED_COLOR;
  const finalDasharray = isCommitted ? undefined : VSCODE_UNCOMMITTED_DASHARRAY;
  paths.push({
    d: dStr,
    colorIndex: color,
    colorHex: finalHex,
    order,
    kind: 'line',  // 旧：'shadow' + 'line' 双层
    isCommitted,
    dasharray: finalDasharray,
  });
};
```

**`frontend/src/views/TimelineNewView.vue:2595-2620` `flow-group` 模板**：

```vue
<g v-for="pg in pathGroups" :key="pg.id" class="flow-group"
   :class="[pg.colorClass, { 'flow-group--dimmed': pathGroupsDimmed.has(pg.id) }]"
   :data-color="pg.colorIndex">
  <path v-if="pg.d" :d="pg.d"
        :stroke="pg.colorHex ?? '#888'"
        :stroke-width="2"  <!-- 旧：shadow=4 + line=2 -->
        :stroke-opacity="pathGroupsDimmed.has(pg.id) ? 0.35 : 1"
        :stroke-dasharray="pg.dasharray"
        fill="none" stroke-linecap="round" vector-effect="non-scaling-stroke" />
</g>
```

`RenderedPath.kind` 类型从 `'line' | 'shadow'` 缩到 `'line'`（vscode-render.ts:90 同步），`PathGroup.kind` 同步缩到 `'line'`（TimelineNewView.vue:1437）。

vscode-office GraphSvg.tsx 渲染线段只画一遍 stroke-width=2，对齐 office 的 CommitTable 不画"光晕底"（vscode-git-graph Branch.drawPath:149-159 描边宽 4 + 半透明 + 描 stroke-width=2 实色的双层画法是 vscode-git-graph 风格）。

### 4. Stash dot 改双圈（vscode-office 风格）

**保留手风琴**：用户上一轮明确拍板"前端 UI 复刻全部 UI 显示，但是保留手风琴功能"。本 commit 改动**不触及** `git-graph-rows` flex 布局 + `activeExpandY` 展开面板机制，手风琴交互完整保留。

## 已知风险

1. **行高 24 + ref badge 22px**：badge 高度 22 > row 24 = 8%（之前 v0.8.35.2 是 28 / 22 = 79%）。视觉上 badge 略压 row，跟 v0.8.35.2 引入的"ref badge 留垂直呼吸空间"目标有矛盾——但跟 vscode-office 1:1 对齐更重要。如需"badge 压 row 太明显"，v0.8.38 可以把 badge 高度 22 → 18（vscode-git-graph 紧凑版本）。
2. **offsetX 8 + 当前 4 grid 列**：graph 占位列宽 row content 可能略紧（之前 16 + 4*16 = 80， 现在 8 + 4*16 = 72，-8px）。需要真仓库验证，但因为 graph 列是动态宽度（通过 `data-col="0"` 列 width 撑开），内容列感受不到影响。
3. **stash 双圈只在 PathGroup 模板层添加**：vscode-render.ts 不感知 stash 概念（前端 stage 渲染），所以 stash 节点在 vscode-render.ts 已经画到正确 `isStash` 字段（`node.isStash` 由 layout 调用方标记），前端只需要读这个字段。
