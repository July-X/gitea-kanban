# v0.8.35.2 — commit 行高 24 → 28 + ref badge 放大对齐示意图

## 问题

v0.8.35.1（commit `14d331e3`）回退到 24px row + 18px badge，但用户截图反馈
badge 仍然"太小"，要求按示意图再次放大：commit 行高改 28px，badge
色块 + 文字布局对齐示意图（色块贴 badge 左缘，紧跟 label 文字）。

## 测量

通过 PIL 像素分析参考图 25（clipboard-20260731-191839.167757-000025）：
- 蓝色实心色块 ~ 22x22，跟 commit 文字基线对齐（不是色块比 row 还高）
- 色块右侧紧跟灰色文字（无 padding 间距）
- badge 整体 ~ 22-24px 高（含边框）

## 修改

| 元素 | v0.8.35.1 | v0.8.35.2 (这次) | 备注 |
|------|-----------|------------------|------|
| `VSCODE_GRID_Y` | 24 | **28** | 行高 +17% |
| `.ref-badge` height | 18 | **22** | badge 79% 行高 |
| `.ref-badge` font-size | 12 | **13** | 略大 |
| `.ref-badge` padding | 0 6px | **0 8px 0 0** | 色块贴左缘 + 右侧 8px 间距 |
| `.ref-badge__icon` | 16x16 | **22x22** | 撑满 badge 高度 |
| `.ref-badge__icon` margin-right | 4 | **6** | 色块 + 文字间距 |
| `.ref-badge__icon` border-radius | 默认 0 | **4px 左两角** | 衔接 badge 左缘圆角 |
| Tag/GitBranch SVG size | 12 | **14** | 跟 22px icon 匹配 |

**保留 v0.8.35 视觉升级**：
- 白色文字 `#E6EDF3`
- 透明 bg + lane 色 border
- hover 填充 lane 色 + 文字变深
- SVG stroke 用 currentColor（hover 跟随变化）

**关键设计点**：
- `.ref-badge__icon` 加 `border-top-left-radius: 4px; border-bottom-left-radius: 4px`，
  让色块跟 badge 圆角左缘无缝衔接（不重叠成方块）
- padding 不再左右对称：`0 8px 0 0` 让色块占满左缘、label 文字靠右
- 圆角由 badge 5px → 色块 4px（让色块略缩进 badge 边框 1px）
