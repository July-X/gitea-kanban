# v0.9.x — Git Graph 展开 commit-row 后左侧 Graph 错位修复（方案 A）

> 修复"仓库选择新的，本地没有的仓库，同步后，Git Graph 没有立即刷新为新的仓库的记录，还是久的，需要手动在刷新操作一次"——以及同一个 handoff 中的第二个 bug：**"修复 commit row 如果点开最新的提交行，展开后，左侧的 Graph 有错位的情况"**。

---

## Bug 根因（精准定位）

`vscode-render.ts` 算展开行后续 row 的位置时，全部用**固定常量** `VSCODE_EXPAND_Y = 250`（vscode config.ts:278 expandY 默认值）：

```ts
// vscode-render.ts:478
const cy = node.row * gridY + offsetY + (expandedAt !== null && node.row > expandedAt ? expandY : 0);

// vscode-render.ts:510-514
const height = graph.nodes.length * gridY + offsetY - gridY/2 + (expandedAt !== null ? expandY : 0);
```

但真实 commit-row 展开后，accordion 内容高度由 DOM 决定（commit message 长度 + files 数量 + GPG 签名块等），典型 250–450px，**vscode 默认 250 不是真实值**。

### 错位机制

```
展开某行后 SVG 计算（固定 +250px）：
  ┌─ ROW_H ─┐ ROW_H  ROW_H ...
  ├ commit ─┤ commit commit
  └─ +250 ─┘ +250   +250  ← SVG dot 在这里
  但 DOM 实际（真实 350px）：
  ┌─ ROW_H ─┐ ROW_H   ROW_H ...
  ├ commit ─┤ commit commit
  │ accordion ┘
  │ 真实 350px   ↑ 下一个 commit-row 应在这里
  └─ +350 ────────┘     ← 实际 DOM 位置

差异：SVG 把后续 dot 推 +250，DOM 把后续 row 推 +350 → **错位 ~100px**
```

## 修复方案 A ——「让 svgHeight 包含真实 accordion 高度」

### 改动 1：`frontend/src/lib/gitgraph/vscode-render.ts`

`RenderOptions` 加 `expandedHeight?: number` 参数：

```ts
const expandY = options?.expandedHeight && options.expandedHeight > (options.expandY ?? VSCODE_EXPAND_Y)
    ? options.expandedHeight     // 优先用真实 DOM scrollHeight
    : (options?.expandY ?? VSCODE_EXPAND_Y);  // fallback 到 250
```

`expandedHeight > expandY` 守卫避免测量异常时 SVG 反而变矮。**全函数复用 `expandY` 局部变量**——SVG height + dot cy + path 端点偏移（line 326-352 的 `y1 += expandY; y2 += expandY`）全部跟着 actual 值走。

### 改动 2：`frontend/src/views/TimelineNewView.vue`

```ts
return renderGraphVscode(dto, {
  expandedAt: expandedRow.value,
  expandY: activeExpandY.value || undefined,
  expandedHeight: expandedHeight.value || undefined,  // v0.9.x：DOM scrollHeight
  maxWidth: svgMaxWidth.value,
  gridY: dynamicGridY.value,
  offsetY: dynamicOffsetY.value,
});
```

`expandedHeight.value` 已经在 commit 展开时由 `measureRowHeights` 函数持续监测量（line 1453 附近，`ResizeObserver` 监听 commit-row 高度变化，accordion 内容变化时滚动 height 更新到 expandedHeight.value）。**测量链路完整**。

### 改动 3：2 个回归测试（`frontend/src/lib/gitgraph/__tests__/vscode_render.test.ts`）

```ts
test('expandedHeight 实际 accordion 高度替换默认 expandY=250', () => {
  // 模拟 accordion 真实高度 350，传入 expandedHeight
  const r = renderGraphVscode(graph, {
    expandedAt: 0,
    expandY: VSCODE_EXPAND_Y,         // 250 fallback

  });
  // row 1/2 的 cy 必须按 350 偏移，不能用 250
  // SVG height = N*gridY + offsetY - gridY/2 + 350
});

test('expandedHeight < expandY 时 fallback 到 expandY', () => {
  // 测量异常时（expandedHeight 100 < expandY 250）保留 expandY 兜底
});
```
