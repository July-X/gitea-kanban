# v0.8.38 — Git Graph commit row 字体增大 + overflow 修复 + 详情面板文本换行 + 设计文档固定

## 问题

3 个用户反馈问题：

1. **commit row 字体偏小**：主体 13px / author 12px / sha 11px 在高分辨率屏上偏小
2. **横向滚动条 + 文字被裁**：`.commit-row__col--desc` 的 `overflow: visible hidden` 值写反了——x=visible 导致超长文字不截断出横向滚动条，y=hidden 导致 commit-subject 文字下半部分被裁只显示一半
3. **展开面板文本不换行**：`.cd-panel__message` 的 `overflow: hidden`（双向裁切）导致换行后的文本被裁掉

## 修改

### 1. commit row 字体全部 +1px

| 元素 | 修改前 | 修改后 |
|---|---|---|
| `.commit-row` 主体 | 13px | **14px** |
| `.ref-badge` | 13px | **14px** |
| `.ref-badge__label` | 13px | **14px** |
| `.commit-author` | 12px | **13px** |
| `.commit-time` | 12px | **13px** |
| `.commit-sha` | 11px | **12px** |

### 2. overflow 值修复

**根因**：`.commit-row__col--desc` 注释写"x=hidden y=visible"，但实际值 `overflow: visible hidden` 是 x=visible + y=hidden（写反了）。

| 属性 | 修改前（bug） | 修改后 |
|---|---|---|
| `.commit-row__col--desc` overflow | `visible hidden` | `hidden visible` |

修复后：
- x=hidden → 超长文字正常截断为省略号，不再出横向滚动条
- y=visible → commit-subject 文字完整显示，ref-badge 底边线不被裁

同时移除之前加的 `padding-bottom: 2px; margin-bottom: -2px` 和 `margin-bottom: 1px` 两个 hack（不再需要）。

### 3. author/date/sha 列补全文字截断

给 `.commit-row__col--author`、`.commit-row__col--date`、`.commit-row__col--sha` 三列补了 `overflow: hidden` + `text-overflow: ellipsis` + `white-space: nowrap`，确保超长作者名/日期/SHA 也不会撑出横向滚动条。

### 4. 详情面板文本换行修复（CommitDetailPanel.vue）

| 元素 | 修改前 | 修改后 | 说明 |
|---|---|---|---|
| `.cd-panel__message` overflow | `hidden` | `hidden visible` | y=visible 让换行文本完整可见 |
| `.cd-panel--panel .cd-panel__message` overflow | `hidden` | `hidden visible` | 同上 |
| `.cd-message__title` | 无 `white-space` | 加 `white-space: normal` | 显式声明换行 |
| `.cd-message__body` | 无 `overflow-wrap` | 加 `overflow-wrap: anywhere` | 超长无空格文本也能折行 |

### 5. ref-badge 底边线修复（上一轮遗留）

移除了之前加的 `margin-bottom: 1px` hack。overflow 修好后 badge 底边线自然完整可见。

### 6. 设计文档固定

更新 `docs/design/06-gitgraph.md`，固定当前 Git Graph 设计方案和要素：
- 核心几何参数表（GRID_X/Y/OFFSET/VERTEX_RADIUS 等）
- lane 颜色调色板
- commit row 布局规范（5 列 grid + 字体大小表 + 文本截断规则表）
- ref badge 设计规范（视觉属性 + icon + label）
- dot 视觉规范
- path 渲染规范
- 详情面板（手风琴）布局 + 文本换行规则表
